# Keyword research — everyday topics (H2 2026)

> **Brief:** find 20–30 *everyday* topic blocks for arahkaii.com — the "Tatler of
> Singapore," modest-luxury, zero-alcohol — where a new (DR-0) domain can realistically
> rank. Companion to `keyword-research-2026-h2.md` (the 90-day calendar's backing data);
> this file widens the net toward high-frequency, local, everyday search intent that the
> current backend under-serves.
>
> **Source:** live Ahrefs API v3 (`keywords-explorer/matching-terms` + `serp-overview`,
> country = Singapore), pulled 21 Jul 2026. ~18k API units. `SG` = Singapore volume ·
> `g` = global volume · `KD` = keyword difficulty (0–100) · ⊛ = AI-Overview present in
> SERP · ★ = SERP-verified beatable for a DR-0 site (top-10 has low-DR blogs / Reddit /
> social) · ⚠ = KD is misleading, see note.

## Why this list exists — the backend gap

The published backend is **21 `style` + 10 `beauty` posts** (mostly *global* fashion/beauty
— Paris/Milan/Seoul fashion week, quiet luxury, it-bags) against **2 `dining` · 2 `travel`
· 3 `living` · 2 `people`**. That inverts where the searchable, everyday, *Singapore*
demand actually is. Every block below is chosen to (a) sit in an under-weighted pillar, (b)
carry real SG volume at KD a DR-0 site can win, and (c) let us differentiate with the
**halal / modest / alcohol-free reframe** that no incumbent (Tatler, CNA Luxury, Vogue SG,
Harper's) applies.

**Operating rule (unchanged):** lead KD 0–5 on thin/social SERPs; cluster for topical
authority; win the halal/modest reframe of lists competitors rank for but never filter;
question-format H2 + a standalone answer sentence for ⊛ AI-Overview terms.

**Two research cautions for the next pull:**
1. **KD lies on aggregator SERPs.** `things to do in batam` is KD 0 but the top 10 is
   Klook/TripAdvisor/Viator/Trip.com (DR 76–89) — unwinnable head-on. Always SERP-check
   travel head terms; the *halal reframe* is the way in, not the head term.
2. **Seed hygiene.** Raw `hijab` and `tudung` seeds return mostly Indonesian adult-spam
   keywords — useless and off-brand. Use `baju …`, `modest …`, `sports hijab`, `baju raya`
   instead. (Documented so we don't re-pull the noise.)
